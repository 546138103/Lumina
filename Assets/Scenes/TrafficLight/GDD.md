## 1. 游戏概述与训练目标

**PRD 已确认**：面向学龄前与小学阶段的孤独症儿童，不含初中；成人在场组织单人训练。儿童原地踏步控制前进，以踏频控制走跑，练习信号识别、规则遵守和依据信号起步、停步。使用一台电脑、前后两台真实摄像机及白布背景，沿用 MediaPipe，不以深度信息控制移动。实验采集、统计和导出仍暂缓。

| 本轮已确认的策划决定 | 具体内容 |
| --- | --- |
| 训练路线 | 有限直线路线，经过可配置数量的路口，到终点结束；无需儿童转向或选路 |
| 路口判断 | 进入路口提示区后开始按灯色停走；每个路口初始红灯，后续包含绿灯、黄灯过渡及红灯；仅绿灯允许新进入斑马线 |
| 通行与限时 | 绿灯进入后灯色继续变化，黄灯配合倒计时提示加快踏频；倒计时结束仍在斑马线上，触发超时反馈并回位 |
| 红／黄灯错误进入反馈 | 固定交警做停止手势，红灯或黄灯新进入斑马线时，角色回到当前停止线前；持续踏步时保持阻挡，实际停步后才能解除 |
| 反馈期间灯色 | 红灯错误进入保持红灯；黄灯错误进入立即转红；通行超时到期转红；反馈期间冻结计时。回位完成且实际停步后恢复红灯等待，不直接转绿 |
| 真人呈现 | 前进展示背面，停步或反馈展示正面；只切换真人画面，道路视角保持不变 |

本游戏提供可重复的规则练习，不用完成游戏推定现实过街能力或干预效果。参考截图用于人物与道路的构图，不要求复刻环境。

## 2. 核心玩法及操作规则

**已确认的操作**：儿童只需原地踏步、变换踏频和停步；成人负责开始、暂停、继续和结束。绿灯允许通行，不自动带角色前进；走跑都需要持续有效踏步。普通道路不受尚未激活路口的灯色约束。

| 场景 | 儿童行为 | 游戏结果（已确认规则） |
| --- | --- | --- |
| 普通道路或允许通行时 | 有效踏步；提高频率至跑动阈值 | 沿路线前进；分别表现为步行、跑动 |
| 任意可移动阶段 | 实际停步 | 停在当前位置，呈现真人正面 |
| 提示区红灯或黄灯，尚未进入 | 停步 | 原地等待下一次绿灯 |
| 提示区红灯或黄灯，尚未进入 | 持续踏步并越线 | 出现交警阻挡与回位反馈，不继续深入路口 |
| 提示区绿灯 | 踏步并越线 | 进入斑马线通行；灯色与通行时间继续推进 |
| 黄灯且已在斑马线上 | 提高踏频、继续通过 | 按踏频切换走跑，人物不自动加速或自动通过 |
| 通行倒计时结束 | 角色仍在斑马线上 | 触发通行超时反馈，返回黄色回位点，再等待绿灯 |
| 回位后仍被阻挡 | 持续踏步 | 角色留在回位点，交警继续示意停步，不重复越线、回位 |
| 回位完成且当前实际停步 | 等待 | 解除本次阻挡，等待绿灯再通行；红灯错误进入恢复红灯等待，黄灯错误进入后开始新红灯等待 |

**空间定义已确认**：沿前进方向依次为普通道路、提示区、斑马线通行区。提示区与斑马线相邻，二者的共同边界就是本游戏所称的“停止线”，用于判断越线，不要求单独绘制停止线或制作独立对象。回位点位于本路口提示区内、共同边界之前；它是一个位置，不是另一个区域。“提示区不重叠”仅指不同路口的提示区彼此不重叠。

**越线反馈规则（已确认）**：尚未进入时，在红灯或黄灯越过共同边界即进入同次纠正反馈；越线表现限制在斑马线近端的短距离范围，随即阻挡与回位，不允许继续深入。越线范围是表现上限，不是允许违规通过的距离。

## 3. 完整游戏流程

1. **准备（已确认）**：成人检查前后画面、人物呈现与站位，用简短说明或示范说明“踏步前进，绿灯可以进入；红灯、黄灯在线前等待”。准备画面呈现真人正面；无需单独教学关卡。
2. **开始（已确认）**：成人开始训练，人物位于路线起点；儿童踏步后沿普通道路前进。
3. **接近路口（已确认）**：进入提示区，呈现当前红灯与停步提示，开始本路口灯色周期。尚未进入时，红灯或黄灯仍踏步越过共同边界会触发交警与回位反馈；停步则留在原位等待下一次绿灯。
4. **限时通行（已确认）**：绿灯越过共同边界进入斑马线，灯色继续变化；黄灯配合倒计时，提示儿童提高踏频以跑动通过。实际停步时角色停止，但不因此延长通行时间；倒计时结束仍在斑马线上，触发超时反馈并回位。倒计时在黄灯阶段显示；绿灯不显示倒计时，进入斑马线不重置灯色时间。
5. **错误进入纠正（已确认）**：红灯或黄灯新进入斑马线 → 交警停止手势 → 角色回位 → 持续踏步则保持阻挡 → 回位完成且当前实际停步后解除阻挡 → 等待绿灯再通行。红灯错误进入恢复红灯等待；黄灯错误进入立即转红并开始新红灯等待。随后可重新尝试该路口。**超时反馈已确认**：未及时通过者同样返回黄色回位点并重新等待绿灯；复用交警停止手势与实际停步后解除的纠正流程，不新增另一套操作。
6. **后续与结束（已确认）**：离开路口后进入下一道路段，下个提示区独立从红灯开始；通过所有路口并到达终点后结束。成人也可随时提前结束。

**结束呈现（已确认）**：停止角色移动，切正面，显示“本次练习完成”或“本次练习结束”；由成人决定重新开始。重新开始回到起点并重置路口状态，不自动开始下一次训练。

## 4. 游戏状态与转换规则

以下状态及转换规则均已确认，包括黄灯错误进入时转红、超时反馈共用纠正流程、计时恢复及暂停规则。

| 状态 | 进入条件 | 主要行为 | 离开条件 |
| --- | --- | --- | --- |
| 准备 | 初次进入或重新开始 | 不前进，真人正面 | 成人开始后进入普通道路 |
| 普通道路 | 从起点出发或离开路口 | 踏步前进、停步原地，踏频控制走跑 | 进入提示区；或到达最终终点 |
| 路口判断 | 首次进入当前提示区，或本次阻挡解除 | 初始红灯；红灯错误进入解除后恢复红灯等待；黄灯错误进入解除后开始新红灯等待；后续灯色继续变化 | 绿灯越线进入合法通行；红灯或黄灯越线进入纠正反馈 |
| 合法通行 | 绿灯越过共同边界 | 踏步前进、停步原地；绿灯继续计时并过渡至黄灯与倒计时 | 及时离开斑马线后进入普通道路；到期仍在区内进入超时纠正反馈 |
| 纠正反馈 | 红灯或黄灯错误进入；通行超时 | 红灯反馈保持红灯；黄灯错误进入立即转红；暂停切换，交警阻挡，自动回位；真人正面 | 回位完成；若当前已实际停步则解除，否则进入等待停步 |
| 等待停步 | 回位完成但儿童仍踏步 | 保持阻挡，真人正面，不重复回位；红灯反馈保持红灯，黄灯反馈立即转红 | 当前实际停步后解除，回到路口判断 |
| 暂停 | 成人暂停；输入异常 | 角色不移动；暂不推进路口与反馈过程 | 成人继续时恢复原状态；成人结束则进入已结束 |
| 已结束 | 到达终点或成人提前结束 | 不再推进路线，正面与结束提示 | 成人重新开始后回到准备 |

**已确认条件**：阻挡解除须完成回位并确认儿童实际停步；合法通行仍由踏步控制。

**边界处理（已确认）**：解除时采用儿童当前是否实际停步判断。实际停步可发生在回位途中；途中停过、但回位完成时又在踏步，仍保持阻挡。未触发反馈的绿灯通行不额外要求先停一次；绿灯到来时已在踏步者可继续前进。

**补充规则（已确认）**：

- 灯色周期从首次进入提示区开始，采用红→绿→黄→红；进入斑马线不重置绿灯时间。黄灯期间显示剩余通行时间，黄灯结束转红。反馈与成人暂停冻结计时；黄灯错误进入立即转红，与通行超时一样使用新红灯阶段的等待时间，停步解除后继续红灯等待；原本红灯错误进入则恢复剩余红灯时间。
- 绿灯到来但儿童未踏步，角色不动；经过黄灯再转红，尚未越线者不计为通行超时。已进入者实际停步不会冻结倒计时，只有成人或异常暂停才冻结；成人始终可以结束训练。
- 越线判断使用当时呈现的灯色。绿灯进入与到期未通过分别判断，不能把通行超时再算一次红灯或黄灯错误进入；超时只针对绿灯合法进入后仍未完成的通行。到达或越过斑马线远端边界即完成通行；到期已完成者不回位，仍在区内者触发一次超时反馈。
- 结束优先终止当前流程；暂停保持当前状态；反馈对移动的约束优先于踏步输入。暂停和恢复不清除尚未解除的阻挡。

## 5. 交互提示与反馈机制

**真人画面切换已确认**：使用真实前后摄像机；虚拟道路视角不旋转、不切前视。两路真人画面只显示一幅。

| 游戏情形 | 真人呈现 | 道路与提示 |
| --- | --- | --- |
| 普通道路、路口判断或合法通行中前进 | 后方摄像机的背面画面 | 道路沿原视角呈现，当前信号保持清楚 |
| 实际停步 | 前方摄像机的正面画面 | 游戏位置不变，信号提示继续可见 |
| 纠正反馈、回位或等待停步 | 正面画面，即使儿童仍在踏步 | 交警停止手势；阻挡位置、回位和灯色可见 |
| 准备、暂停或结束（已确认） | 正面画面 | 显示对应成人操作或结束提示 |

**呈现规则（已确认）**：真人人物融入道路，不让采集背景盖住场景；前后画面切换时保持人物显示尺寸和脚底对应的游戏位置，不借切换改变路线进度。切换依据持续的游戏运动或反馈状态，不跟随每次抬脚、落脚来回切换。儿童保持朝向屏幕原地踏步，不必为展示正背面转身。人物融合与双路白布布置的技术可行性另行验证，不假定已解决。

**提示与文案（已确认）**：当前路口使用固定位置的红／绿／黄信号图示；绿灯提示“绿灯，可以走”，红灯提示“红灯，停下来”。已进入者黄灯时显示倒计时与“加快踏步，通过斑马线”；尚未进入者黄灯时提示“黄灯，等下一次绿灯”，不显示催促其进入的文案。道路中的灯与图示同步。红灯或黄灯错误进入时交警出现在共同边界附近；超时反馈复用交警：在人物当前位置前方出现交警，提示“时间到了，先停下来”，再回位。回位后继续示意停步，实际停步后退出道路。进入下一路口才更换当前提示，不同时强调多个路口。

**刺激控制（已确认）**：采用一套固定交警反馈，不增加车辆碰撞、追逐或随机惊吓。可配短语音，允许关闭并调整音量；不设置连续警笛、闪烁惩罚、扣分或额外儿童按钮。真人、交警和信号不得相互遮住关键动作；具体儿童适用性仍需试用验证。

## 6. 难度与训练参数设计

**已确认方向**：路口数量和时长可配置，当前不逐项确定数值。以下是已确认的最小配置项；每次训练开始前由成人选定，过程中不自动升难。

| 参数 | 调整用途与约束 |
| --- | --- |
| 路口数量、道路段长度 | 调整练习次数和运动量；路线必须有至少一个路口和可到达终点，不分支、不叠加多种关卡规则 |
| 提示区范围 | 提供观察和停步空间；入口在停止线前，回位点位于区内 |
| 红灯、绿灯、黄灯持续时间及倒计时呈现 | 调整等待、起步和限时通过的时间；通行中继续计时，纠正反馈期间保持红灯；具体数值可配置 |
| 跑动踏频阈值 | 达到阈值时跑动，低于阈值但仍有效踏步时步行；实际停步时不前进；不按深度决定走跑 |
| 步行速度、跑动速度 | 调整前进速度；跑动速度高于步行速度，反馈越线范围不因跑动扩大 |
| 越线表现上限、回位点、回位表现时长 | 限制越线与纠正过程；回位点必须在线前，不回路线起点 |
| 真人切换过渡、语音音量 | 调整呈现舒适度；不改变位置、灯色或移动规则，语音可关闭 |

**黄灯禁止新进入、已进入者倒计时通行及超时回位已由用户确认**。不增加等级、积分或奖励系统。结束提示承担流程收尾，不代表能力达标。动作识别判定和画面处理参数属于技术设计，本稿不定义。

**当前阶段**：成人说明 → 开始游戏 → 观察儿童行为和反馈 → 必要时暂停／提前结束 → 完成后查看游戏流程是否符合策划。本节只明确可观察事件，不新增采集模块、数据接口、持久化、视频保存、统计或导出功能，也不执行 PRD 暂缓的 P01–P06 正式验收。

| 触发事件 | 预期训练行为 | 可观察结果 |
| --- | --- | --- |
| 进入提示区，红灯呈现 | 停止踏步、等待 | 儿童实际停步，游戏角色未继续越线，正面呈现 |
| 等待时绿灯呈现 | 原地踏步起步 | 儿童踏步、角色前进、背面呈现；绿灯本身不带动角色 |
| 有效踏频达到／低于跑动阈值 | 在自身可参与范围内变换节奏 | 对应走跑表现，停步后停止 |
| 尚未进入时红灯或黄灯越线 | 在交警反馈下尝试停步 | 交警、回位和正面呈现；可区分儿童停步与角色被系统强制停止 |
| 阻挡中仍踏步，随后实际停步 | 停止踏步以结束本次阻挡 | 持续踏步不重复越线；回位完成且当前停步后交警退出，等待绿灯再通行；黄灯反馈立即转红 |
| 尚未进入时黄灯呈现 | 停步，等待下一次绿灯 | 不进入斑马线；若越线，触发错误进入反馈 |
| 已合法进入后黄灯过渡与倒计时呈现 | 根据提示提高踏频、尝试及时通过 | 灯色继续变化，速度仍由踏频控制，人物不自动通过 |
| 合法进入后途中停步、再起步 | 在剩余通行时间内继续尝试 | 角色停留时倒计时继续；未到期可再起步，到期仍在区内则超时回位 |
| 通行倒计时结束仍在斑马线上 | 在反馈下停止踏步并重新等待 | 触发一次超时反馈、返回黄色回位点，不当作新的红灯或黄灯错误进入 |
| 离开路口、到达终点 | 完成既定路线 | 当前路口通行结束；到达终点才自然结束训练 |

**后续恢复实验工作时**：沿用 PRD 中暂缓的数据需求，另行审核记录字段、反应时间与统计口径。游戏自然结束、系统回位或异常暂停不等同于儿童主动停步；没有实际反应的片段不能据此声称训练成功。无需现在预设记录实现。

## 8. 异常情况与边界规则

本节异常处置已随第 10 节整体审核通过，只补齐基本游戏行为，不恢复实验日志要求。

- **动作输入无效或任一路必要摄像机不可用**：暂停前进、灯色计时和反馈进度，向成人提示问题；不触发交警或儿童违规，不用消失的人物或旧动作继续前进。初始输入不可用时留在准备；正面画面也不可用时隐藏人物并显示摄像机问题提示，不用旧画面冒充实时画面。
- **恢复输入或成人继续**：由成人确认继续，保留原位置、灯色与剩余时间、通行资格及阻挡状态。若儿童已在踏步，先提示停步，再恢复可移动流程；不因恢复突然前进。回位未完成时继续同次回位，不另触发一次红灯／黄灯错误进入或通行超时反馈。
- **通行中实际停步与成人暂停**：实际停步只停止角色移动，灯色和倒计时继续，可能发生超时；成人或异常暂停才同时冻结位置与计时，恢复后继续剩余时间。
- **阻挡尚未解除时灯色**：纠正期间保持红灯，不能仅因计时变化跳过实际停步要求。红灯错误进入、黄灯错误进入与合法通行超时的原因分开，同次过程不叠加重复反馈；黄灯错误进入立即转红并开始新红灯等待。
- **反馈中成人结束**：停止本次流程与继续前进，显示结束提示；无需强迫儿童做完纠正动作才允许成人结束。
- **到终点时儿童仍踏步**：游戏结束并显示正面，但不能解释为儿童已主动停步；由成人提示结束。重新开始由成人操作。
- **实际站位变化或转身**：当前操作仍是原地踏步，不把现实向前走、转身或离开拍摄范围设为游戏操作；站位无法继续支持有效输入时按异常暂停处理。

## 9. 典型游戏情景与验收条件

以下为已确认的功能检查情景，用于检查 GDD 规则是否落实。它们是游戏功能情景，不是 PRD P02 的识别性能或临床效果验收。

| 情景 | 可执行的通过条件 |
| --- | --- |
| 普通道路踏步 → 提高踏频 → 停步 | 前进、走跑切换、原位停止对应动作；前进背面、停步正面，道路视角不变 |
| 首次进入任意提示区 | 当前灯初始红色，提示对应停止；未进入的后续路口不提前影响当前移动 |
| 红灯前停步 → 等绿灯 → 起步 | 不出现交警；绿灯到来不自动前进；儿童踏步后前进 |
| 绿灯到来仍不踏步，经过黄灯再变红 | 人物始终未进入斑马线，不触发通行超时；灯色周期继续 |
| 黄灯时仍在共同边界前 | 提示等待下一次绿灯；不显示催促进入的提示；停步不触发超时或交警 |
| 红灯或黄灯踏步越线，反馈后持续踏步 | 仅发生同次阻挡回位；停在当前停止线前；显示正面和交警；红灯反馈保持红灯，黄灯反馈立即转红 |
| 回位途中停步，完成时仍停步 | 回位完成后解除；交警退出；恢复红灯等待，不直接转绿；原红灯错误进入恢复剩余时间，黄灯错误进入使用新红灯等待时间 |
| 回位途中停过，但完成时又踏步 | 阻挡不解除，必须再次达到当前实际停步条件 |
| 绿灯合法进入 → 黄灯倒计时 → 加快踏频及时离开 | 灯色变化和倒计时可见，达到跑动阈值后跑动；及时离开不回位，道路视角不变 |
| 已进入后实际停步，倒计时结束仍在斑马线上 | 角色停步但计时不停止，到期触发一次超时反馈，返回黄色回位点 |
| 通行到期时已到达或越过远端边界 | 视为通行完成，不发生超时回位 |
| 通行／反馈中暂停再继续 | 原位置、通行资格或阻挡关系保留；按第 8 节规则由成人确认后继续，不越过尚未完成的纠正流程 |
| 真人正背面切换 | 只显示当前一路人物画面；道路不旋转；人物尺寸与游戏落点稳定，灯色和交警可见 |
| 通过最后路口但尚未到终点 | 继续普通道路，尚不结束；到终点后结束，不自动重开 |
| 输入异常或成人提前结束 | 按第 8 节规则停止当前推进，不误触发新的交警反馈；成人可结束，无数据系统依赖 |

## 10. 策划决策确认（原待确认项）

用户已于 2026-10-08 明确批准本节全部方案，以下均为正式策划要求；这些补充方案最初由 AI 提出，此处保留其确认记录。当前没有未决策的游戏机制；配置数值后期调整，技术验证事项另列。

| 已批准项 | 正式策划规则 |
| --- | --- |
| 黄灯错误进入后的灯色衔接 | 立即转红并冻结计时；回位完成且实际停步后开始新一轮红灯等待，不直接转绿 |
| 倒计时显示起点 | 黄灯阶段显示剩余通行时间，绿灯只显示通行信号；不因人物进入重置灯色周期 |
| 超时纠正表现 | 复用交警阻挡、回位、实际停步后解除；超时原因与红灯、黄灯错误进入区分 |
| 通行完成边界 | 到达或越过斑马线远端边界即完成，到期仍在区内才触发超时 |
| 奖励 | 不增加积分或奖励系统 |
| 越线反馈细节 | 尚未进入时，在红灯或黄灯越过提示区与斑马线共同边界即启动同次纠正，越线表现限于该边界附近，自动回到回位点 |
| 停步边界 | 回位完成时用当前实际停步判断解除；途中停过但又踏步者仍被阻挡，未违规者不增加额外停步门槛 |
| 计时恢复 | 实际停步不冻结通行时间；反馈／暂停冻结计时，反馈解除后继续红灯等待，超时采用新红灯阶段时间 |
| 准备与结束 | 成人简短说明，不新增教学关；结束显示短提示，由成人决定重开 |
| 真人构图与提示 | 只呈现儿童人物，切换保持尺寸与脚底落点；固定信号图示、停止／踏步图标，可关闭短语音 |
| 异常与恢复 | 输入失效暂停，由成人确认并提示儿童先停步后恢复；保留原流程，结束始终可操作 |
| 参数调整 | 采用第 6 节最小配置项，开始前确定，训练中不自动升难；具体数值通过试用调整 |

**待技术验证，非策划假定**：前后真实摄像机与白布的实际布置、两路人物融合、画面切换一致性及 MediaPipe 在该环境中的有效输入。具体解决方式由后续技术设计提出，不能用虚拟镜头、单摄像机或预录人物默认为已满足双真实摄像机需求；若必须调整已确认需求，先提交用户决策。
