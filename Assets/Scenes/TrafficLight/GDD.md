# TrafficLight 红绿灯情境训练游戏策划案（GDD）

状态：完整策划草案，待用户审核。日期：2026-10-08。依据：[PRD.md](./PRD.md)、[GLOSSARY.md](./GLOSSARY.md)及本轮逐项确认。项目路径相对于 `Lumina` 根目录。

**标记规则**：“已确认”来自 PRD 或用户本轮选择；“建议”是 AI 补充的可执行方案，审核前不视为已批准。参数数值后期配置。本稿只描述玩法与呈现，不包含代码、算法、类、接口或通信设计；完成后暂停，不进入技术开发。

## 1. 游戏概述与训练目标

**PRD 已确认**：面向学龄前与小学阶段的孤独症儿童，不含初中；成人在场组织单人训练。儿童原地踏步控制前进，以踏频控制走跑，练习信号识别、规则遵守和依据信号起步、停步。使用一台电脑、前后两台真实摄像机及白布背景，沿用 MediaPipe，不以深度信息控制移动。实验采集、统计和导出仍暂缓。

| 本轮已确认的策划决定 | 具体内容 |
| --- | --- |
| 训练路线 | 有限直线路线，经过可配置数量的路口，到终点结束；无需儿童转向或选路 |
| 路口判断 | 进入路口提示区后开始按灯色停走；每个路口初始红灯，进入前按可配置时长红绿交替 |
| 合法通行 | 绿灯进入后，保持绿灯直至离开路口；途中停步，游戏角色也停止 |
| 违规反馈 | 固定交警做停止手势，角色回到当前停止线前；持续踏步时保持阻挡，实际停步后才能解除 |
| 反馈期间灯色 | 保持红灯，暂停切换；完成回位且儿童实际停步后恢复红灯等待，停步不直接触发绿灯 |
| 真人呈现 | 前进展示背面，停步或反馈展示正面；只切换真人画面，道路视角保持不变 |

本游戏提供可重复的规则练习，不用完成游戏推定现实过街能力或干预效果。参考截图用于人物与道路的构图，不要求复刻环境。

## 2. 核心玩法及操作规则

**已确认的操作**：儿童只需原地踏步、变换踏频和停步；成人负责开始、暂停、继续和结束。绿灯允许通行，不自动带角色前进；走跑都需要持续有效踏步。普通道路不受尚未激活路口的灯色约束。

| 场景 | 儿童行为 | 游戏结果（已确认规则） |
| --- | --- | --- |
| 普通道路或允许通行时 | 有效踏步；提高频率至跑动阈值 | 沿路线前进；分别表现为步行、跑动 |
| 任意可移动阶段 | 实际停步 | 停在当前位置，呈现真人正面 |
| 提示区红灯 | 停步 | 原地等待灯色切换 |
| 提示区红灯 | 持续踏步并越线 | 出现交警阻挡与回位反馈，不继续深入路口 |
| 提示区绿灯 | 踏步并越线 | 合法通行，绿灯保持至离开路口 |
| 回位后仍被阻挡 | 持续踏步 | 角色留在回位点，交警继续示意停步，不重复越线、回位 |
| 回位完成且当前实际停步 | 等待 | 解除本次阻挡，恢复红灯等待，随后按正常切换通行 |

**空间定义建议**：每个路口依次具有提示区入口、停止线、线后短距离阻挡范围、路口出口。回位点在提示区内且位于停止线前；提示区互不重叠。红灯越线即进入纠正反馈，角色的越线表现限制在停止线附近，随即阻挡与回位，不允许继续深入。越线范围是表现上限，不是允许违规通过的距离。

## 3. 完整游戏流程

1. **准备（建议）**：成人检查前后画面、人物呈现与站位，用简短说明或示范说明“踏步前进，红灯停，绿灯走”。准备画面呈现真人正面；无需单独教学关卡。
2. **开始（已确认）**：成人开始训练，人物位于路线起点；儿童踏步后沿普通道路前进。
3. **接近路口（已确认）**：进入提示区，呈现当前红灯与停步提示，开始本路口红绿交替。红灯仍踏步时可以发生短距离越线，随后触发反馈；停步则留在原位等待。
4. **绿灯通行（已确认）**：儿童踏步，越过停止线后进入合法通行；灯保持绿色。中途停步不触发违规，重新踏步可继续，直至离开路口。
5. **违规纠正（已确认）**：交警停止手势 → 角色回位 → 持续踏步则保持阻挡 → 回位完成且当前实际停步后解除阻挡 → 恢复红灯等待。随后可重新尝试该路口。
6. **后续与结束（已确认）**：离开路口后进入下一道路段，下个提示区独立从红灯开始；通过所有路口并到达终点后结束。成人也可随时提前结束。

**结束呈现建议**：停止角色移动，切正面，显示“本次练习完成”或“本次练习结束”；由成人决定重新开始。重新开始回到起点并重置路口状态，不自动开始下一次训练。

## 4. 游戏状态与转换规则

以下按已确认玩法划分状态；回位点、剩余时间恢复和暂停细节采用建议方案，见表后说明。

| 状态 | 进入条件 | 主要行为 | 离开条件 |
| --- | --- | --- | --- |
| 准备 | 初次进入或重新开始 | 不前进，真人正面 | 成人开始后进入普通道路 |
| 普通道路 | 从起点出发或离开路口 | 踏步前进、停步原地，踏频控制走跑 | 进入提示区；或到达最终终点 |
| 路口判断 | 首次进入当前提示区，或本次阻挡解除 | 首次进入时初始红灯，阻挡解除时恢复当前红灯；未通行时红绿交替 | 绿灯越线进入合法通行；红灯越线进入违规反馈 |
| 合法通行 | 绿灯越过停止线 | 踏步前进，停步原地；保持绿灯 | 离开路口后进入普通道路 |
| 违规反馈 | 红灯越线 | 保持红灯、暂停切换，交警阻挡，自动回位；真人正面 | 回位完成；若当前已实际停步则解除，否则进入等待停步 |
| 等待停步 | 回位完成但儿童仍踏步 | 保持阻挡和红灯，真人正面，不重复回位 | 当前实际停步后解除，回到路口判断 |
| 暂停 | 成人暂停；异常暂停采用建议规则 | 角色不移动；暂不推进路口与反馈过程 | 成人继续时恢复原状态；成人结束则进入已结束 |
| 已结束 | 到达终点或成人提前结束 | 不再推进路线，正面与结束提示 | 成人重新开始后回到准备 |

**已确认条件**：阻挡解除须完成回位并确认儿童实际停步；合法通行仍由踏步控制。

**边界处理建议**：解除时采用儿童当前是否实际停步判断。实际停步可发生在回位途中；途中停过、但回位完成时又在踏步，仍保持阻挡。未违规的绿灯通行不额外要求先停一次；绿灯到来时已在踏步者可继续前进。

**补充建议**：

- 红绿交替计时从首次进入提示区开始；违规及暂停保留剩余时间，解除后从剩余红灯时间继续，不重新初始化路口。
- 普通路口判断中，绿灯到来但儿童未踏步，角色不动；绿灯到期再回红灯，不算违规。合法通行中等待多久都保持绿灯，成人可暂停或结束。
- 越线判断使用儿童当时实际看到的当前灯色。绿色越线归为合法通行；既已合法进入，不因停步或暂停撤销资格。
- 结束优先终止当前流程；暂停保持当前状态；反馈对移动的约束优先于踏步输入。暂停和恢复不清除尚未解除的阻挡。

## 5. 交互提示与反馈机制

**真人画面切换已确认**：使用真实前后摄像机；虚拟道路视角不旋转、不切前视。两路真人画面只显示一幅。

| 游戏情形 | 真人呈现 | 道路与提示 |
| --- | --- | --- |
| 普通道路、路口判断或合法通行中前进 | 后方摄像机的背面画面 | 道路沿原视角呈现，当前信号保持清楚 |
| 实际停步 | 前方摄像机的正面画面 | 游戏位置不变，信号提示继续可见 |
| 违规、回位或等待停步 | 正面画面，即使儿童仍在踏步 | 交警停止手势；阻挡位置、回位和灯色可见 |
| 准备、暂停或结束（建议） | 正面画面 | 显示对应成人操作或结束提示 |

**呈现建议**：真人人物融入道路，不让采集背景盖住场景；前后画面切换时保持人物显示尺寸和脚底对应的游戏位置，不借切换改变路线进度。切换依据持续的游戏运动或反馈状态，不跟随每次抬脚、落脚来回切换。儿童保持朝向屏幕原地踏步，不必为展示正背面转身。人物融合与双路白布布置的技术可行性另行验证，不假定已解决。

**提示建议**：当前路口使用固定位置的红／绿信号图示，配停止／踏步图标及短文本“红灯，停下来”“绿灯，可以走”；道路中的灯与图示同步。交警位于停止线后的短距离阻挡范围内，停止手势朝向画面，出现时显示“先停下来”；回位完成后继续示意停步，实际停步后退出道路。进入下一路口才更换当前提示，不同时强调多个路口。

**刺激控制建议**：采用一套固定交警反馈，不增加车辆碰撞、追逐或随机惊吓。可配短语音，允许关闭并调整音量；不设置连续警笛、闪烁惩罚、扣分或额外儿童按钮。真人、交警和信号不得相互遮住关键动作；具体儿童适用性仍需试用验证。

## 6. 难度与训练参数设计

**已确认方向**：路口数量和时长可配置，当前不逐项确定数值。以下是建议的最小配置项；每次训练开始前由成人选定，过程中不自动升难。

| 参数 | 调整用途与约束 |
| --- | --- |
| 路口数量、道路段长度 | 调整练习次数和运动量；路线必须有至少一个路口和可到达终点，不分支、不叠加多种关卡规则 |
| 提示区范围 | 提供观察和停步空间；入口在停止线前，回位点位于区内 |
| 红灯、绿灯持续时间 | 调整等待与允许起步的时间；合法通行和违规反馈期间遵守已确认的保持规则 |
| 跑动踏频阈值 | 达到阈值时跑动，低于阈值但仍有效踏步时步行；实际停步时不前进；不按深度决定走跑 |
| 步行速度、跑动速度 | 调整前进速度；跑动速度高于步行速度，反馈越线范围不因跑动扩大 |
| 越线表现上限、回位点、回位表现时长 | 限制越线与纠正过程；回位点必须在线前，不回路线起点 |
| 真人切换过渡、语音音量 | 调整呈现舒适度；不改变位置、灯色或移动规则，语音可关闭 |

**建议不设置黄灯、等级、积分或奖励系统**，先验证红停绿行这一组规则。结束提示承担流程收尾，不代表能力达标。动作识别判定和画面处理参数属于技术设计，本稿不定义。

## 7. 实验流程与行为记录需求

**当前阶段**：成人说明 → 开始游戏 → 观察儿童行为和反馈 → 必要时暂停／提前结束 → 完成后查看游戏流程是否符合策划。本节只明确可观察事件，不新增采集模块、数据接口、持久化、视频保存、统计或导出功能，也不执行 PRD 暂缓的 P01–P06 正式验收。

| 触发事件 | 预期训练行为 | 可观察结果 |
| --- | --- | --- |
| 进入提示区，红灯呈现 | 停止踏步、等待 | 儿童实际停步，游戏角色未继续越线，正面呈现 |
| 等待时绿灯呈现 | 原地踏步起步 | 儿童踏步、角色前进、背面呈现；绿灯本身不带动角色 |
| 有效踏频达到／低于跑动阈值 | 在自身可参与范围内变换节奏 | 对应走跑表现，停步后停止 |
| 红灯越线 | 在交警反馈下尝试停步 | 交警、回位和正面呈现；可区分儿童停步与角色被系统强制停止 |
| 阻挡中仍踏步，随后实际停步 | 停止踏步以结束本次阻挡 | 持续踏步不重复越线；回位完成且当前停步后交警退出，红灯恢复等待 |
| 合法进入后途中停步、再起步 | 维持通行规则，按动作控制前进 | 绿灯保持，角色停留后可继续，不自动送到出口 |
| 离开路口、到达终点 | 完成既定路线 | 当前路口通行结束；到达终点才自然结束训练 |

**后续恢复实验工作时**：沿用 PRD 中暂缓的数据需求，另行审核记录字段、反应时间与统计口径。游戏自然结束、系统回位或异常暂停不等同于儿童主动停步；没有实际反应的片段不能据此声称训练成功。无需现在预设记录实现。

## 8. 异常情况与边界规则

本节的异常处置均为**AI 建议，待审核**，只补齐基本游戏行为，不恢复实验日志要求。

- **动作输入无效或任一路必要摄像机不可用**：暂停前进、灯色计时和反馈进度，向成人提示问题；不触发交警或儿童违规，不用消失的人物或旧动作继续前进。初始输入不可用时留在准备；正面画面也不可用时隐藏人物并显示摄像机问题提示，不用旧画面冒充实时画面。
- **恢复输入或成人继续**：由成人确认继续，保留原位置、灯色与剩余时间、通行资格及阻挡状态。若儿童已在踏步，先提示停步，再恢复可移动流程；不因恢复突然前进。回位未完成时继续同次回位，不另触发一次违规。
- **绿灯通行中停步／暂停**：保留绿灯和当前位置；恢复有效踏步后继续。停得久不强制移动，也不自动判训练失败。
- **绿灯期间阻挡尚未解除**：按已确认规则不应出现，违规时已保持红灯；不能仅因灯色变化跳过实际停步要求。
- **反馈中成人结束**：停止本次流程与继续前进，显示结束提示；无需强迫儿童做完纠正动作才允许成人结束。
- **到终点时儿童仍踏步**：游戏结束并显示正面，但不能解释为儿童已主动停步；由成人提示结束。重新开始由成人操作。
- **实际站位变化或转身**：当前操作仍是原地踏步，不把现实向前走、转身或离开拍摄范围设为游戏操作；站位无法继续支持有效输入时按异常暂停处理。

## 9. 典型游戏情景与验收条件

以下用于检查 GDD 规则是否落实；含建议方案的条目须先审核。它们是游戏功能情景，不是 PRD P02 的识别性能或临床效果验收。

| 情景 | 可执行的通过条件 |
| --- | --- |
| 普通道路踏步 → 提高踏频 → 停步 | 前进、走跑切换、原位停止对应动作；前进背面、停步正面，道路视角不变 |
| 首次进入任意提示区 | 当前灯初始红色，提示对应停止；未进入的后续路口不提前影响当前移动 |
| 红灯前停步 → 等绿灯 → 起步 | 不出现交警；绿灯到来不自动前进；儿童踏步后前进 |
| 绿灯到来仍不踏步，直至又变红 | 人物一直原位，无违规反馈；切换仍按当前周期继续 |
| 红灯踏步越线，反馈后持续踏步 | 仅发生同次阻挡回位；停在当前停止线前；保持红灯，显示正面和交警 |
| 回位途中停步，完成时仍停步 | 回位完成后解除；交警退出；恢复剩余红灯等待，不直接转绿 |
| 回位途中停过，但完成时又踏步 | 阻挡不解除，必须再次达到当前实际停步条件 |
| 绿灯合法进入 → 停步 → 再踏步离开 | 始终保持绿灯，停步正面、前进背面；位置连续，不出现回位 |
| 通行／反馈中暂停再继续 | 原位置、通行资格或阻挡关系保留；按第 8 节建议确认后继续，不越过尚未完成的纠正流程 |
| 真人正背面切换 | 只显示当前一路人物画面；道路不旋转；人物尺寸与游戏落点稳定，灯色和交警可见 |
| 通过最后路口但尚未到终点 | 继续普通道路，尚不结束；到终点后结束，不自动重开 |
| 输入异常或成人提前结束 | 按第 8 节建议停止当前推进，不误触发新的交警反馈；成人可结束，无数据系统依赖 |
