# TrafficLight 红绿灯情境训练游戏需求文档

状态：当前需求基线已确认；后续暂缓建议仍待审核。日期：2026-10-08。本文记录当前游戏开发需求及后续暂缓事项，不作为游戏策划案（GDD）或技术设计文档。本文的项目路径均相对于 `Lumina` 项目根目录（`.`）。

“已确认”表示用户在需求讨论中明确提出或认可；第 6 节保留后续实验数据需求及 P01–P06 验收建议，整体暂缓，不属于当前阶段交付范围；策划建议另列，不能作为已批准的开发要求。术语见同目录的 [GLOSSARY.md](./GLOSSARY.md)。

## 1. 目标、用户与使用环境（已确认）

- **游戏目标**：通过道路与路口红绿灯情境，提供识别交通信号、按规则前进和停止的练习，作为面向孤独症谱系障碍儿童的干预研究原型。当前阶段以游戏功能可运行为检查依据，数据采集与训练效果评估留到后续阶段。
- **训练重点**：规则识别与遵守，以及依据信号起步、停步。踏步频率控制走跑是核心交互方式。
- **适用范围**：学龄前与小学阶段的孤独症儿童，不含初中；不以统一年龄数字替代实际阶段和参与能力。
- **部署环境**：一台电脑、前后两台真实摄像机和一张用于提供纯净背景的白布；儿童在拍摄范围内原地踏步。两路拍摄的具体背景布置待技术验证。
- **使用方式**：成人在场组织的单人训练。儿童通过体感参与；研究人员或老师负责开始、暂停和结束训练；数据导出暂缓。
- **输入环境**：沿用项目已有的摄像头与 MediaPipe 体感输入。儿童在现实中原地踏步，控制游戏角色前进。
- **产品取向**：重技术、轻交互，首版体量较小，围绕核心训练流程提供必要操作。

## 2. 当前阶段核心功能（已确认）

| 编号 | 需求 | 可观察的行为 |
| --- | --- | --- |
| R01 | 道路与路口情境 | 场景包含可前进的道路，以及带交通信号灯的路口。参考素材只用于理解道路和信号情境，不要求复刻视频。 |
| R02 | 原地踏步控制前进 | 儿童开始有效踏步时，角色前进；停止踏步时，角色停止前进。 |
| R03 | 踏步频率控制走跑 | 使用踏步频率区分步行与跑动；达到阈值后进入跑动。具体阈值和速度在后续阶段确定。 |
| R04 | 红灯停、绿灯行 | 红灯要求儿童停止踏步并等待；绿灯允许通过踏步控制角色通行。 |
| R05 | 违规后的阻挡与回位 | 红灯时继续踏步，角色越过停止线并进入路口一小段后，出现阻挡反馈，随后角色返回当前路口停止线前的位置。 |
| R06 | 停步后解除阻挡 | 回位后，儿童持续踏步时保持阻挡，避免反复越线、回位；确认儿童实际停步后解除本次阻挡，绿灯时允许重新踏步通行。系统强制角色静止不能替代儿童实际停步。 |
| R07 | 成人训练操作 | 成人能够开始、暂停和结束训练。实验数据导出留到后续阶段。 |
| R09 | 真人画面呈现 | 将儿童实时画面放入游戏，采用第三人称呈现；前进时展示后方摄像机拍到的背面，实际停步或进入反馈阶段时展示前方摄像机拍到的正面。道路场景视角保持不变，只切换真人画面；当前信号灯、停止线和交警仍保持可见。 |

本轮 GDD 讨论已确认首版使用固定交警，通过停止手势、回位和等待实际停步完成反馈；车辆等其他表现不纳入当前策划。“回位”指返回当前路口停止线前，不是返回整段道路的起点。

## 3. 当前开发重点（已确认）

- **游戏逻辑**：踏步前进、频率控制走跑、红灯停绿灯行、违规阻挡与回位，以及实际停步后解除阻挡。
- **游戏内容**：道路、路口、信号灯、角色及阻挡反馈所需内容；具体布局和表现留到 GDD 确定。
- **技术使用**：沿用 MediaPipe，完成不依赖深度信息的踏步输入、角色控制，以及双真实摄像机的人物实时画面呈现。双摄选择由用户明确提出，不是 AI 新增需求。
- **必要成人操作**：能够开始、暂停和结束游戏。
- **本阶段交付目标**：先形成可运行的核心游戏流程；不要求实验数据系统、统计报表、导出功能或 P01–P06 的正式验收。踏步频率仍需实时计算用于控制，但暂不采集成实验记录或持久化保存，也不要求为此预先设计数据接口。

## 4. 范围与约束（已确认）

- 首版沿用 MediaPipe，不使用深度信息作为控制依据；踏步频率是走跑切换依据。
- 当前阶段聚焦游戏逻辑、场景内容、MediaPipe 体感控制及必要成人操作。实验记录、数据处理和详细验收整体暂缓，后续单独安排。
- 当前编写 GDD；完成后等待用户审核，不自动进入技术设计或代码开发。
- 保持现有社交情绪部分稳定。TrafficLight 的功能文件归入 `Assets/Scenes/TrafficLight`，脚本放在其 `Scripts` 中，其他专属资源按现有简单布局放置；第三方资源包放在 `Assets/ThirdParty`。暂不新建共用文件夹。

### P01 参与条件与部署检查

- 在成人陪同下，儿童能够稳定站立，尝试交替原地踏步，并在简单说明、图片或示范帮助下尝试起步、停步。无需参加前已掌握红绿灯规则，也不要求识字、口头复述或快速踏步。
- 成人开始前检查儿童的可参与状态、摄像机画面和背景；白布位于儿童身后，光线稳定，画面可持续覆盖动作识别所需的身体部位，包括双腿与双脚。白布不应妨碍站立或踏步空间。
- 同一时刻识别一名儿童。首次验证使用实际部署的电脑、摄像机、白布及游戏显示画面；硬件型号与软件版本写入验收记录，不在 PRD 预设未经测试的最低配置。
- 摄像机视野或站位不合适时，在开始训练前提供成人可理解的提示。儿童可通过惯用方式表达休息或停止，由成人暂停或结束训练。

### P02 识别质量与响应验收

- 以成人观察或人工标注的实际踏步、停步为参照，分别检查起步响应、停步响应和静止误触发，不能只检查角色是否移动。
- **建议验收目标**：每位验证参与者至少检查 20 次起步和 20 次停步；在有效识别条件下，各自至少 90% 能在实际动作变化后 1 秒内产生对应角色响应。静止观察 1 分钟内，不出现持续超过 1 秒的误前进。
- 验证应覆盖参与者能够舒适完成的慢、快踏步及走跑切换。左右动作幅度不同不能直接计为儿童错误；身体遮挡或识别丢失单独报告。
- 以上是工程验收建议，不是儿童能力标准或已测得性能。正常、静止、异常片段均保留验证结果；异常不能用于事后删除不利样本，且不能把系统暂停冒充正确停步识别。走跑阈值、识别算法和具体参数留到后续阶段。

### P03 实验指标口径

| 指标 | 建议定义与计数规则 |
| --- | --- |
| 违规次数 | 红灯要求停止时，角色因儿童持续踏步越过当前停止线，记一次。一次阻挡与回位过程只计一次；回位后持续踏步不重复加次数。无效识别引起的移动标为技术异常，不归为儿童违规。 |
| 起步反应时间 | 在角色可通行、儿童原本停步且识别有效的条件下，从绿灯通行指令实际呈现到儿童首次有效踏步，单位为秒。已经在踏步的片段不作为起步反应测量。 |
| 停步反应时间 | 在儿童正在踏步且识别有效的条件下，从红灯停止指令实际呈现到儿童实际停步，单位为秒。阻挡造成角色静止不能作为结束事件；原本已停步的片段不记为 0 秒反应。 |
| 无有效反应值 | 条件不满足、指令后未观察到目标反应，或测量途中暂停、识别失效，保留原因，反应时间留空，不填 0，不当成正常测量。有效观察窗口由后续实验方案确定。 |
| 踏步频率 | 单位为步/分钟；左脚或右脚各完成一次有效踏步，分别计一步。过程记录附训练内时间与识别有效状态；估计方法及记录间隔留到技术设计。 |
| 时间与完成情况 | 同时保留整次训练时长、有效训练时长、暂停及识别异常时段；有效时长只包含训练运行且识别有效的时段。正常完成、成人提前结束、技术中断分别记录，完成条件留到策划阶段。 |

事件记录应覆盖灯色指令呈现、有效起步、实际停步、违规、阻挡与回位、暂停恢复、识别异常和训练结束。数据时间以同一训练内的时间基准关联，不能仅有汇总分数；踏频汇总注明计算所用有效时段，避免把暂停或异常当作零频率。

### P04 数据导出与本地管理

- 后续实验版本建议采用 UTF-8 CSV，导出训练概况、事件明细和踏频过程三类数据；每条记录均可关联匿名儿童编号和训练标识，字段名与单位保持一致。
- 匿名编号由成人录入并持续复用；每次开始训练生成独立训练标识。多次训练不得覆盖旧记录。建议概况包含年龄或年级、训练日期、有效时长、完成状态，以及用于比较的程序版本和训练配置标识。
- 数据保存到电脑上的本地可写位置，向成人显示保存目录；支持按儿童或训练记录选择导出，并选择导出位置。后续实验版本不增加云同步、账号系统或联网依赖。
- 后续实验版本不保存儿童真实姓名、原始摄像视频、录音或姿态关键点。首次开始前检查保存位置能否写入；失败时提示成人并阻止开始，以免出现已训练却未记录的情况。
- 每次训练结束后检查保存结果；导出失败保留已有记录并允许重试。保留历史记录，不自动按日期清理；确需删除时由成人明确操作并确认。机构实验数据保留期限由独立实验方案确定。

### P05 异常、中断与成人提示

- 摄像机不可用、画面缺少参与者或姿态识别无效时，暂停角色移动与行为判定，提示成人，并记录异常开始、恢复或结束。暂停期间不新增儿童违规。
- 成人暂停时停止角色移动和行为判定；识别恢复后由成人确认继续，不自动让角色突然前进。暂停、异常的持续时间及原因应可导出。
- 训练中记录保存失败时，暂停并提示成人；保留能够恢复的数据，记录缺失范围。不能把部分数据标为完整训练；无法恢复时允许成人结束并保留技术中断状态。
- 建议提供成人简单标记“口头提示、示范、身体协助”的入口，区分独立完成与协助后完成；标记由成人操作，不要求儿童增加交互，也不要求系统自动推断。
- 中断前已经产生的有效记录应可保存和导出；软件意外退出后保留已经成功写入的记录，对能够识别的未正常结束训练标为中断，不能保证尚未写入的数据。

- 路口数量、路线长度、红绿灯时长、越线范围、回位表现时长、走跑阈值与速度等数值作为可配置参数，后续试用调整。
- 黄灯、奖励及其他未明确选定的补充方案仍须区分 AI 建议与用户确认。
