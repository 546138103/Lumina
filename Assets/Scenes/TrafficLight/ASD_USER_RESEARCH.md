# TrafficLight 目标儿童年龄、动作与理解能力调研

调研日期：2026-10-08。用途：为同目录 [PRD.md](./PRD.md) 中“目标儿童适用范围”提供依据。本文是定向资料调研，不是系统综述、临床评估、GDD 或技术设计；以下项目建议均未转为已确认需求。项目内路径以 `Lumina` 根目录为基准。

## 1. 可以先得出的结论

**孤独症并不限定于某个儿童年龄段，也不能按年龄直接判断动作或理解能力。** ASD 属于神经发育状况，特征通常在生命早期出现，但可在任何年龄被诊断，并可能持续终生；“儿童”是本项目选择的服务对象，不是 ASD 本身的年龄限制。同龄儿童的优势、困难和支持需求可以明显不同。[NIMH：Autism Spectrum Disorder](https://www.nimh.nih.gov/health/publications/autism-spectrum-disorder)

对当前游戏，更有用的描述是：“在成人陪同和合适提示下，能够稳定站立、尝试原地交替踏步，并尝试依简单提示起步或停步的儿童”。这是一项**待审核的项目参与能力建议**，不要求儿童参加前已经掌握红绿灯规则、停得快、踏得快或能流利说话。

如果需要先收窄首轮试点，可以考虑 **6–12 岁**，方便从学龄儿童开始验证可操作性。但这是项目组织上的候选范围，**不是医学推荐年龄，也没有证据证明是最佳年龄段**。下列研究在学龄样本中观察了运动和语言能力，不能据此排除年龄较小或较大的儿童。

## 2. 年龄范围怎样理解

先区分三件事：实际年龄、各项能力的发展水平、研究招募范围。它们不能互相代替。NICE 要求相关支持根据儿童的发展水平调整，并考虑其理解方式和感觉敏感性；不能把某项语言或运动表现简化成一个“整体能力年龄”。[NICE CG170：实施重点](https://www.nice.org.uk/guidance/cg170/chapter/key-priorities-for-implementation)

下表是**项目验证范围的建议分组**，不是“到了某个年龄就具备某项能力”的医学表。

| 年龄分组 | 对当前项目的判断 | 尚需实际观察的内容 |
| --- | --- | --- |
| 3 岁以下 | 当前证据不足以支持直接定位为首版对象；低龄并不等于不能接受支持 | 是否适合当前站立踏步任务，需另行验证，不从诊断年龄推导 |
| 3–5 岁 | 可作为后续可行性探索对象，不能默认能独立完成流程 | 示范后能否尝试动作、注意屏幕、表达不适；需要多少成人协助 |
| 6–12 岁 | 可考虑首轮试点，但仍按具体能力与支持需求判断 | 站立踏步、简单提示理解、屏幕与动作的对应关系 |
| 13–17 岁 | 不因年龄自动排除；儿童化表现是否合适也需了解本人偏好 | 同样观察动作和理解能力，并核查任务是否过易或失去参与兴趣 |

首轮如果仅招募 6–12 岁，最终结论也应限定在实际参加的样本及支持条件，不能宣称适用于所有 ASD 儿童。

## 3. 动作能力：会走路不等于踏步控制没有困难

运动能力应分开观察：站立平衡、左右交替协调、动作模仿、节奏稳定性、变速和停止。ASD 儿童可能在部分领域有困难，也可能有较好的表现；不能用“运动能力差”概括每个儿童。CDC 列出运动发展延迟等可能特征，同时明确并非每个儿童都有这些表现。[CDC：ASD 的表现与特征](https://www.cdc.gov/autism/signs-symptoms/index.html)

原始研究提供的主要依据如下，数字均是相应研究样本，不能直接作为本项目发生率或纳入阈值。

| 原始研究 | 样本与年龄 | 可以支持的结论 | 外推限制 |
| --- | --- | --- | --- |
| Bhat，2020，SPARK | 最终纳入 11,814 名 ASD 儿童，5–15 岁 | 86.9% 在家长填写的 DCDQ 上被识别为运动困难风险；学龄后仍需关注运动情况 | 排除了报告有智力障碍或部分神经运动问题的样本；没有后续临床复核。风险不等于确诊，也不等于不能踏步。[原文](https://pmc.ncbi.nlm.nih.gov/articles/PMC7297441/) |
| Kaur 等，2018，动作与协调比较 | 24 名 ASD 儿童与 12 名年龄匹配的典型发展儿童，5–12 岁 | 在该样本中，ASD 两个不同认知分组均有运动困难，踏步等节律动作的波动也较大；认知表现不能替代动作观察 | 小样本、横断面比较；研究提供了简短指令、示范和练习，不能当成所有儿童无支持操作的证明。[原文](https://pmc.ncbi.nlm.nih.gov/articles/PMC5743591/) |
| Chen 等，2024，语言理解与表达差异 | 1,579 名少言语 ASD 儿童及青少年，5–18 岁 | 理解与表达能力差异明显；在同时具有相应家长量表数据的 1,311 人中，317 人（24.18%）的理解能力显著高于表达能力 | 特定少言语群体、数据库与测量条件限制，不能推广为所有 ASD 儿童的语言分布。[原文](https://pmc.ncbi.nlm.nih.gov/articles/PMC10922817/) |

以上运动研究并未验证当前 MediaPipe 游戏。“年龄较大的儿童自然没有运动困难”“风险比例就是不能完成游戏的比例”均不成立；横断面年龄比较也不能证明某个儿童随时间一定不会改善。

**对项目的推论：** 应容纳动作幅度、节奏和速度的个体差异，不能将快速踏步作为默认参与前提。走跑切换是已有交互需求，但儿童是否能舒适地改变频率，应通过实际可行性观察确认；具体识别算法和参数留到技术设计阶段。

## 4. 理解能力：要区分听懂、表达和执行

“理解”至少涉及：理解简单指令、识别屏幕信号、理解动作会控制角色、学会信号对应的规则，以及在运动中执行规则。某一项完成困难，不能自动归因于全部理解能力不足。语言研究尤其提醒：不能从口语少就推断理解少，也不能默认所有少言语儿童理解均高于表达。[Chen 等：研究摘要](https://pubmed.ncbi.nlm.nih.gov/38149732/)

表达还可能通过手势、图片或电子交流设备完成；口头说明可以结合视觉提示或动作示范。因此，本项目可用动作表现和儿童惯用交流方式观察理解，而不把口头复述、认字或解释交通规则设为默认参与条件。[CDC：支持与干预中的交流及教育方式](https://www.cdc.gov/autism/treatment/index.html)

这里也应分清**参与前提和训练目标**：能在适当提示下尝试“开始、停止”，可用于判断能否参与；是否独立按红绿灯起步、停步，才是训练中要观察的表现。若招募时只接纳已熟练做到后者的儿童，会提前筛掉需要练习的人。

## 5. 建议观察的功能表现（未确认）

以下是项目可行性观察，不是诊断工具，不规定医学分数、IQ 阈值或固定测试时长。判断重点是儿童需要什么支持，以及当前交互是否适合。

| 观察项 | 可直接观察的内容 | 需要区分的情况 |
| --- | --- | --- |
| 站立与参与 | 能否在成人陪同下稳定站立并尝试踏步，是否明显不适 | 动作本身困难、疲劳与摄像头识别失败 |
| 动作尝试 | 简单说明或示范后能否尝试左右交替踏步、起步和停步 | 没听懂、没看到提示、不会做、暂时不愿做 |
| 交互对应 | 是否逐渐发现踏步与角色前进的关系 | 尚未建立对应关系与系统输入不稳定 |
| 提示理解 | 口头、图片或示范中，哪种方式帮助儿童尝试任务 | 独立完成、成人提示后完成与身体协助完成 |
| 感觉与反馈 | 对屏幕声音、角色阻挡和回位的实际反应 | 能接受、需要调整与需要暂停 |
| 交流与意愿 | 能否通过惯用方式表达继续、休息、停止或不适 | 没有口语表达与没有意愿表达不能混同 |

NICE 提醒关注个体对光线、声音等的感觉反应，并采用对该儿童有意义的视觉支持。**项目建议**是让成人能依据反应调整或暂停；不能预设交警、车辆阻挡对所有儿童都能起到同样作用。[NICE CG170：环境与支持调整](https://www.nice.org.uk/guidance/cg170/chapter/key-priorities-for-implementation)

## 6. 对实验数据解释的影响（未确认建议）

1. **保留样本背景。** 使用匿名编号，可考虑记录实际年龄、必要的动作能力观察及惯用提示方式；仅收集分析所需信息，不新增身份资料要求。
2. **记录提示水平。** 成人每次是否提醒或示范，会影响起步、停步和违规表现。独立完成与提示后完成应可区分，才能解释同一儿童多次训练的变化。
3. **分开技术与行为原因。** 丢帧、遮挡、识别不到、暂停和提前结束可能改变系统反应时间。不要把角色被强制停住当作儿童已经停步，也不要把识别异常算成规则不理解。
4. **限制结论强度。** 停步慢可能同时受指令理解、注意、动作控制或疲劳影响；违规次数不是 ASD 严重程度测量。单次进步不能证明干预有效；屏幕中的规则表现也不能直接证明现实过街安全能力。

这些是根据任务结构提出的测量解释建议。是否新增记录字段、如何区分提示与异常、是否验证现实情境迁移，仍需在 PRD 审核及后续独立实验方案中确认。

## 7. 证据边界与 PRD 待确认项

本次以 NIMH、CDC、NICE 官方资料和三项原始研究为主，未做完整检索或质量分级。样本主要来自海外，部分研究使用家长量表或少言语样本；年龄跨度、小样本、测量方式和支持条件不同，不足以建立中国儿童按年龄划分的统一能力标准，也未验证本项目的临床效果。个别官网全文访问受到限制，已通过官网检索索引及原始研究摘要交叉核对核心信息。

**供 PRD 审核的建议：** 首轮招募范围可暂考虑 6–12 岁，但须结合实际合作机构儿童情况；参与条件以安全参与、在适当支持下尝试动作和简单提示为中心，不以已掌握红绿灯规则或统一严重程度标签筛选。最终年龄、支持范围和实验纳入条件仍为“待确认”，本文不直接修改 [PRD.md](./PRD.md)，也不进入关卡、机制或技术参数设计。
